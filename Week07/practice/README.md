# 실내 온도 격자의 오전·오후 비교 그림

시설 담당자에게 같은 공간의 오전·오후 온도를 위치별로 비교해 전달한다. 제공 CSV의 12칸에서 위치와 온도의 짝을 보존하고, 두 온도 지도·차이 지도·한 행의 선 그래프를 2×2 subplot의 PNG 한 장으로 완성하는 하나의 실습이다.

## 제공 입력과 실행 환경

제공 파일은 `README.md`와 `cells.csv`다. 한 행은 격자 한 칸의 관측이며 수업용 가상 자료다. `x`와 `y`는 칸 중심의 가로·세로 위치(m), `am`과 `pm`은 같은 칸의 오전·오후 온도(°C)다. 행이 위치 순서로 저장되어 있지 않다.

```csv
x,y,am,pm
2,1,26,27
0,2,24,28
3,0,26,26
1,1,24,26
0,0,20,22
3,2,30,34
1,2,26,29
2,0,24,25
0,1,22,25
3,1,28,27
1,0,22,24
2,2,28,30
```

Python 3, pandas, NumPy, Matplotlib을 사용한다. 예시 구현은 pandas 1.4.4, NumPy 1.24.0, Matplotlib 3.5.2에서 실행했다. 차트의 영문 라벨은 아래 대응표를 따른다. Python 파일과 CSV가 있는 폴더에서 실행한다.

| 명령 | 읽는 대상과 목적 | 바뀌는 파일·확인 결과 |
|---|---|---|
| `python --version` | Python 실행기 확인 | 파일 변경 없이 버전 출력 |
| `python -c "import pandas, numpy, matplotlib; print(pandas.__version__, numpy.__version__, matplotlib.__version__)"` | 설치된 라이브러리 확인 | 파일 변경 없이 세 버전 출력 |
| `python main.py` | 현재 폴더의 `cells.csv`를 읽어 그림 생성 | `output/comparison.png` 생성 또는 덮어쓰기 |

AI로 코드 초안을 작성해도 된다. 실제 출력과 기대값을 직접 대조한다. GUI 창을 띄우지 않고 파일만 저장해도 실습을 완료할 수 있다.

## 처리 순서와 기대 출력

1. CSV를 읽고 `y`, 그다음 `x` 기준으로 **행 전체**를 정렬해 3행×4열 배열 두 개(AM, PM)로 배치한다. 배열의 `[행, 열]`은 `[y, x]` 위치이며 12칸을 모두 유지한다. 온도 열만 따로 정렬하면 위치와 온도의 짝이 깨진다.
2. 같은 인덱스의 두 값을 빼서 차이 배열 `PM − AM`을 만든다.
3. `plt.subplots(2, 2, figsize=(10, 8), constrained_layout=True)`로 네 Axes를 만들고 아래 배치대로 그린다. 네 Axes 사이에 축 공유(`sharex`·`sharey`)는 쓰지 않는다.
   - 위 왼쪽 `axes[0, 0]`·위 오른쪽 `axes[0, 1]`: AM·PM 온도 지도. `imshow`에 `origin="lower"`, `extent=[-0.5, 3.5, -0.5, 2.5]`, `interpolation="nearest"`, `cmap="viridis"`, 공통 색 범위 `vmin=20`, `vmax=32`를 지정하고 각 지도에 컬러바를 붙인다. 상한 32°C를 넘는 값이 있는 지도의 컬러바에만 `extend="max"`를 지정한다.
   - 아래 왼쪽 `axes[1, 0]`: 차이 지도. 같은 `origin`·`extent`·`interpolation`에 `cmap="RdBu_r"`, `vmin=-4`, `vmax=4`를 지정해 0이 컬러바 가운데의 흰색이 되게 하고 컬러바를 붙인다.
   - 아래 오른쪽 `axes[1, 1]`: `y=2` m 행의 AM·PM 온도를 x에 따라 그린 선 그래프. AM은 `-o`, PM은 `--s`로 그리고 왼쪽 위 범례로 구별한다. 세로축은 18~36°C다.
4. 100dpi로 `output/comparison.png`에 저장한다. `bbox_inches="tight"`는 사용하지 않아 이미지 크기를 1000×800픽셀로 유지한다. 실제 파일을 열어 제목·축 라벨·컬러바 라벨·범례가 잘리지 않았는지 확인한다.

정렬·배치 후 기대 배열은 다음과 같다. 각 줄은 한 `y` 위치이며 왼쪽부터 `x=0, 1, 2, 3` m다. 그림에서는 `origin="lower"`이므로 `y=0` 줄이 아래에 놓인다.

| y (m) | AM (°C) | PM (°C) | PM − AM (°C) |
|---:|---|---|---|
| 0 | 20, 22, 24, 26 | 22, 24, 25, 26 | 2, 2, 1, 0 |
| 1 | 22, 24, 26, 28 | 25, 26, 27, 27 | 3, 2, 1, −1 |
| 2 | 24, 26, 28, 30 | 28, 29, 30, 34 | 4, 3, 2, 4 |

예를 들어 칸 `(x=3, y=2)`는 AM 지도 오른쪽 위에서 30°C, PM 지도 같은 위치에서 34°C, 차이 지도에서 +4로 나타난다. PM의 34°C는 공통 상한 32°C를 넘으므로 32°C와 같은 끝 색으로 표시되고, PM 컬러바 위쪽 삼각형이 상한 초과를 알린다. 정확한 34°C는 아래 오른쪽 선 그래프의 `x=3` 점에서 읽는다. AM은 최댓값이 30°C라 상한을 넘지 않으므로 AM 컬러바에는 삼각형을 붙이지 않는다.

| Axes | 제목 | 가로축 | 세로축 | 컬러바·범례 |
|---|---|---|---|---|
| `axes[0, 0]` | `AM temperature` | `x (m)` | `y (m)` | 컬러바 `T (°C)`, 20~32 |
| `axes[0, 1]` | `PM temperature` | `x (m)` | `y (m)` | 컬러바 `T (°C)`, 20~32, 위쪽 삼각형 |
| `axes[1, 0]` | `PM - AM` | `x (m)` | `y (m)` | 컬러바 `PM - AM (°C)`, −4~4 |
| `axes[1, 1]` | `Row y=2 m` | `x (m)` | `T (°C)`, 18~36 | 범례 `AM`, `PM` |

그림에서 오후 온도는 12칸 중 10칸에서 오전보다 높고, `(x=3, y=0)`은 같으며, `(x=3, y=1)`만 1°C 낮다. 공통 색 범위를 썼으므로 두 온도 지도의 같은 색은 같은 °C를 뜻한다. 이 관측만으로 온도 변화의 원인을 확정하지 않는다.

세 배열의 값과 세 지도의 색 범위를 검산하고 파일 저장을 완료하면 터미널에 다음을 출력한다.

```text
OK: 12 cells; 2x2 axes; T 20-32, PM-AM -4..4; 1000x800 pixels
```

이 문장만으로 정답을 판정하지 않는다. PNG의 실제 크기·내용과 재실행 결과를 함께 확인한다.

## 제출 파일과 평가기준

제출물은 `main.py` 한 개와 생성한 `output/comparison.png`다. Python 소스는 빈 줄과 주석을 포함해 100줄 이내다. 개인 이해도는 다음 주 수업 시작 직후 교수자 감독 아래 Discord 비공개 서술형 문항 한 개로 별도 평가한다.

ufunc와 계산 결과 검증

03 · NUMPY

ufunc와 계산 결과 검증

ufunc와 검증 함수의 역할

  • 보편 함수(universal function, ufunc)는 np.add처럼 배열의 각 원소에 같은 계산을 적용해 원소별 결과를 만드는 NumPy 함수이다.
  • np.equal은 정확 비교를 원소마다 수행하고, np.isclose는 허용 오차 비교를 원소마다 수행하며, np.allclose는 모든 허용 오차 판정을 불리언 하나로 묶는다.
  • repr은 representation(표현)의 약자이다. repr(value)는 값을 다시 읽어도 같은 값이 되도록 개발자용 표현을 반환하므로, 지정한 자릿수로 반올림하는 서식 출력과 달리 미세한 차이를 숨기지 않는다.

같은 입력으로 세 판정 비교

  • =는 값을 이름에 저장하는 대입이므로 비교 결과가 없다. ==와 np.equal은 허용 오차 없이 수치가 같은지 비교하므로 0.1+0.2와 0.3을 False로 판정한다.
  • np.isclose(a, b)는 각 원소가 |a-b| ≤ atol + rtol×|b|인지 판정하고, np.allclose는 그 결과가 모두 참인지 답한다.
  • 기본 허용 오차에서 표현 오차 0.30000000000000004는 통과하지만 실제 차이가 큰 0.31은 통과하지 않는다.
PYTHON
import numpy as np
values = np.array([1, 2, 3])
print(np.add(values, 10))       # ufunc 결과 → [11 12 13]

actual = np.array([0.1 + 0.2]) # 계산값 → [0.30000000000000004]
expected = np.array([0.3])     # 기대값 → [0.3]
print(f"{actual[0]:.1f}")     # 소수 첫째 자리 표시 → 0.3
print(repr(actual[0]))
# repr 출력 → 0.30000000000000004
print(np.equal(actual, expected))    # 정확 비교 → [False]
print(np.isclose(actual, expected))  # 허용 오차 비교 → [ True]
print(np.allclose(actual, expected)) # 전체 판정 → True

bad = np.array([0.31])
print(np.allclose(bad, expected))    # 큰 차이의 반례 → False

여러 값을 하나로 줄이는 집계

05 · NUMPY

여러 값을 하나로 줄이는 집계

핵심 개념

  • 집계는 여러 원소를 합계·평균·최솟값·최댓값 같은 더 적은 수의 요약값으로 줄이는 계산이다.
  • axis를 생략하면 전체 값을 하나로 줄이고, axis=1이면 각 행을 하나의 결과로 줄인다.

이 코드를 쓰는 이유

  • 전체 평균은 반 전체의 중심을, 행별 최댓값은 학생마다 가장 높은 점수를 답하므로 질문에 맞는 축을 선택해야 한다.
  • np.isclose(a, b)는 allclose와 같은 허용 오차 규칙을 각 대응 원소에 적용하므로 배열 입력에는 불리언 배열을, 스칼라 입력에는 불리언 하나를 반환한다.
  • isclose는 어느 원소가 실패했는지 보여 주고, allclose는 그 원소별 판정을 모두 묶어 전체 통과 여부 하나를 답한다.
PYTHON
import numpy as np
scores = np.array([[70, 80, 90],
                   [60, 75, 95]])          # 입력 → shape (2, 3)
overall_mean = scores.mean()                # 전체 평균 → 78.333...
row_max = scores.max(axis=1)                # 행별 최댓값 → [90 95]
print(overall_mean, row_max)                # 출력 → 78.333... [90 95]
checks = np.isclose([overall_mean, row_max[0]],
                    [470 / 6, 90])          # 원소별 판정 → [ True  True]
whole = np.allclose([overall_mean, row_max[0]],
                    [470 / 6, 90])          # 전체 판정 → True
print(checks, whole)                        # 출력 → [ True  True] True

집계로 줄어드는 axis 방향

2차원 배열

  • axis=0은 행 방향으로 값을 모아 각 열의 결과를 남긴다.
  • axis=1은 열 방향으로 값을 모아 각 행의 결과를 남긴다.

모양 검산

  • (2, 3) 배열에서 axis=0 집계 결과의 shape는 (3,)이다.
  • (2, 3) 배열에서 axis=1 집계 결과의 shape는 (2,)이다.

결측값을 제외한 집계

07 · NUMPY

결측값을 제외한 집계

NaN

  • NaN(Not a Number)은 부동소수점 배열에서 값이 없거나 유효하지 않음을 나타내는 특별한 값이다.
  • 일반 평균은 NaN을 포함하면 NaN이 되지만 np.nanmean은 NaN을 제외한 값의 평균을 계산한다.

제외 조건

  • np.nanmean의 결과와 함께 제외한 NaN 개수를 기록해야 표본 수의 변화를 알 수 있다.
  • 모든 값이 NaN인 집단은 유효한 평균이 없으므로 0으로 바꾸지 않고 별도로 표시한다.
PYTHON
values = np.array([10.0, np.nan, 20.0])
normal_mean = np.mean(values)       # NaN 포함 평균 → nan
valid_mean = np.nanmean(values)     # NaN 제외 평균 → 15.0
missing = np.isnan(values).sum()    # 제외한 NaN 수 → 1
print(normal_mean, valid_mean, missing)  # 출력 → nan 15.0 1

09 · NUMPY

서로 다른 모양을 맞추는 브로드캐스팅

쉬운 정의

  • 브로드캐스팅은 두 배열의 모양이 달라도 정해진 규칙으로 대응 원소를 정해 계산하는 기능이다.
  • NumPy는 실제로 같은 값을 가득 복사하지 않고 계산에 필요한 방향으로 값이 반복된 것처럼 처리한다.

세 규칙

  • 두 배열의 차원 수가 다르면 모양의 왼쪽에 크기 1인 차원을 보충한다.
  • 같은 위치의 두 차원 크기는 서로 같거나 둘 중 하나가 1이어야 한다.
  • 조건을 만족하지 않는 차원이 하나라도 있으면 두 배열의 연산은 실패한다.

열별 중심 맞추기

11 · NUMPY

열별 중심 맞추기

핵심 개념

  • X의 각 행은 관측 하나이고 각 열은 서로 다른 측정 변수이다.
  • 열 평균 X.mean(axis=0)을 빼면 각 열의 평균이 0인 X_centered를 만든다.

각 줄이 연결되는 이유

  • (2,)인 열 평균은 (3, 2)의 각 행에서 반복해 뺀 것처럼 계산된다.
  • 입력 작성 → 열 평균 계산 → 평균 빼기 → 출력 확인 → 평균 0 검증의 순서로 중심 이동이 맞는지 추적한다.
PYTHON
import numpy as np                              # 배열과 평균 함수를 사용한다.
X = np.array([[1., 10.],
              [3., 14.],
              [5., 18.]])                      # 행=관측, 열=변수인 입력을 만든다.
column_mean = X.mean(axis=0)          # 열 평균 → [ 3. 14.]
X_centered = X - column_mean          # 중심 이동 → [[-2,-4],[0,0],[2,4]]
print(column_mean)                    # 출력 → [ 3. 14.]
print(X_centered)                     # 출력 → [[-2. -4.],[0. 0.],[2. 4.]]
print(X_centered.mean(axis=0))        # 이동 뒤 열 평균 → [0. 0.]

1차원 배열로 만드는 2차원 격자

12 · NUMPY

1차원 배열로 만드는 2차원 격자

함수별 의미

  • np.linspace(start, stop, num)은 시작값과 끝값을 포함해 같은 간격의 값 num개를 만든다. 따라서 간격은 (stop-start)/(num-1)이다.
  • np.linspace(0, 5, 6)의 결과는 [0., 1., 2., 3., 4., 5.]이고, 값 6개 사이의 간격은 5/(6-1)=1이다.
  • np.newaxis는 (2,)인 y에 열 축을 추가해 (2, 1)로 바꾸며, 이 열 배열과 (6,)인 x를 계산하면 (2, 6) 격자가 된다.

그림 읽기

  • 위 예제의 첫 행은 y=0, 둘째 행은 y=10일 때의 여섯 x 결과이며, 행은 y 위치이고 열은 x 위치이다.
  • 교재 Figure 8-2는 같은 규칙을 50×50 좌표와 파동 함수에 적용하고 각 셀의 z 값을 색으로 표시한 확장 사례이다.
PYTHON
x = np.linspace(0, 5, 6)
print(x)                       # → [0. 1. 2. 3. 4. 5.]

y = np.array([0., 10.])[:, np.newaxis]
print(y)                       # → [[ 0.], [10.]]

z = x + y                     # 각 y와 모든 x를 더한다.
print(z)                       # → [[0.,1.,2.,3.,4.,5.],
                               #    [10.,11.,12.,13.,14.,15.]]
print(z.shape)                 # → (2, 6)

비교 연산의 불리언 배열 결과

13 · NUMPY

비교 연산의 불리언 배열 결과

비교 연산

  • 배열 비교는 각 원소가 조건을 만족하면 True, 만족하지 않으면 False인 불리언 배열을 만든다.
  • 불리언 배열의 shape는 비교한 원본 배열의 shape와 같다.

개수 세기

  • np.sum(condition)은 True를 1로 세어 조건을 만족한 원소 수를 계산한다.
  • np.any는 하나라도 참인지 확인하고 np.all은 모든 원소가 참인지 확인한다.
PYTHON
rain = np.array([0, 12, 3, 25, 8])
heavy = rain >= 10                    # 원소별 비교 → [F,T,F,T,F]
count = np.sum(heavy)                 # True를 1로 센 개수 → 2
print(heavy, count)                   # 출력 → [False True False True False] 2

여러 조건을 결합하는 마스크

14 · NUMPY

여러 조건을 결합하는 마스크

불리언 연산자

  • NumPy 배열에서는 원소별 AND에 &, OR에 |, NOT에 ~를 사용한다.
  • 각 비교식을 괄호로 감싸야 비교와 불리언 연산의 계산 순서를 분명하게 만들 수 있다.

마스크 선택

  • rain[moderate]는 원본에서 마스크가 True인 위치의 값만 1차원 배열로 반환한다.
  • 선택 뒤 원소 수는 np.sum(moderate)와 같아야 한다.
PYTHON
rain = np.array([0, 12, 3, 25, 8])
moderate = (rain > 5) & (rain < 20)  # 조건 결과 → [F,T,F,F,T]
selected = rain[moderate]            # True 위치 선택 → [12  8]
print(moderate)                      # 출력 → [False True False False True]
print(selected)                      # 출력 → [12  8]

인덱스 배열로 여러 위치 고르기

16 · NUMPY

인덱스 배열로 여러 위치 고르기

팬시 인덱싱

  • 팬시 인덱싱은 정수 인덱스 배열을 사용해 원하는 여러 위치의 값을 한 번에 선택하는 방법이다.
  • 인덱스의 각 숫자는 원본에서 읽을 위치이며, 결과는 그 숫자의 배치와 같은 모양으로 만들어진다.

마스크와 차이

  • 불리언 마스크는 조건이 참인 위치를 고르고 정수 인덱스 배열은 지정한 위치와 순서를 고른다.
  • 정수 인덱스 배열에는 같은 위치를 여러 번 넣을 수 있다.
PYTHON
x = np.array([10, 20, 30, 40, 50])
index = np.array([[3, 1], [4, 0]])  # 읽을 위치 → shape (2, 2)
selected = x[index]                 # 위치 대응 → 3→40, 1→20, 4→50, 0→10
print(selected)                    # 출력 → [[40 20], [50 10]]
print(selected.shape)              # 출력 shape → (2, 2)

중복 인덱스의 누적 연산

19 · NUMPY

중복 인덱스의 누적 연산

팬시 인덱싱과 중복 위치

  • 팬시 인덱싱은 정수 배열의 숫자를 원본 위치로 사용한다. index=[2,2,3]은 2번 위치를 두 번, 3번 위치를 한 번 가리킨다.
  • 일반 대입은 선택값 [0,0,0]을 [1,1,1]로 만든 뒤 되쓰므로 2번 위치에 같은 값 1을 두 번 덮어써 한 번만 증가한 것처럼 남는다.

히스토그램으로 연결

  • 세 관측의 구간 번호가 [2,2,3]이면 2번 구간에 관측 두 개, 3번 구간에 관측 한 개가 있으므로 빈도는 [0,0,2,1,0]이어야 한다.
  • np.add.at은 인덱스를 하나씩 방문한 것처럼 0→1→2를 보존하므로 입력 관측 수 3과 빈도 합 3이 같아진다.
PYTHON
index = np.array([2, 2, 3])      # 방문 위치 → 2번, 2번, 3번
bad = np.zeros(5, dtype=int)     # 시작값 → [0 0 0 0 0]
bad[index] += 1                  # 중복을 한 번만 반영 → [0 0 1 1 0]

good = np.zeros(5, dtype=int)    # 시작값 → [0 0 0 0 0]
np.add.at(good, index, 1)        # 방문마다 누적 → [0 0 2 1 0]

print(bad)   # 출력: [0 0 1 1 0] — 2번 위치의 한 건이 사라짐
print(good)  # 출력: [0 0 2 1 0] — 2번 위치에 두 건이 누적됨
assert bad.sum() == 2 and good.sum() == 3

구간별 빈도의 직접 누적

20 · NUMPY

구간별 빈도의 직접 누적

계산 흐름

  • np.searchsorted(bins, x)는 정렬된 경계 bins에 각 관측값을 끼워 넣을 위치, 즉 관측이 들어갈 구간 번호를 반환한다.
  • np.add.at(counts, index, 1)은 각 구간 번호가 나타날 때마다 그 구간의 빈도를 1씩 더한다.

검산

  • counts.sum()은 모든 구간의 빈도를 더한 값이며, 위 결과 4는 입력 관측값 네 개가 하나도 빠지지 않았다는 뜻이다.
  • 0.2→0번, 0.7→1번처럼 대표값의 구간 번호를 손으로 대조해 경계 포함 방향도 확인한다.
PYTHON
x = np.array([0.2, 0.7, 1.4, 1.8])       # 관측값 4개
bins = np.array([0.5, 1.0, 1.5, 2.0])    # 경계값 4개
index = np.searchsorted(bins, x)          # 구간 번호 → [0 1 2 3]
counts = np.zeros(len(bins) + 1, dtype=int) # 시작 빈도 → [0 0 0 0 0]
np.add.at(counts, index, 1)               # 구간별 누적 → [1 1 1 1 0]
print(counts.sum())                       # 빈도 합 → 4

값과 정렬 순서의 동시 획득

값과 정렬 순서의 동시 획득

정렬 함수

  • np.sort(x)는 정렬된 복사본을 반환하고 x.sort()는 원본 배열의 순서를 바꾼다.
  • np.argsort(x)는 값을 작은 순서로 읽을 수 있는 원본 인덱스를 반환한다.

선택 기준

  • 값만 필요하면 sort를 사용하고 다른 열도 같은 순서로 재배열해야 하면 argsort를 사용한다.
  • 원본 순서가 의미를 가지면 제자리 정렬 전에 복사본이나 정렬 인덱스를 만든다.
PYTHON
x = np.array([40, 10, 30, 20])
order = np.argsort(x)
print(order)     # 원본 인덱스 순서 → [1 3 2 0]
print(x[order])  # 그 순서로 읽은 값 → [10 20 30 40]

axis별 정렬과 행 관계

22 · NUMPY

axis별 정렬과 행 관계

독립 정렬

  • 독립 정렬은 각 열을 별개의 목록으로 보고 정렬한다. 예제에서 첫 열과 둘째 열을 따로 정렬하면 없던 행 [2,80]과 [3,90]이 생긴다.
  • 원본에서 한 행 [2,90]은 ID 2와 점수 90의 한 관측이므로, 두 값이 정렬 뒤에도 함께 이동해야 행 관계가 보존된다.

행 관계 보존

  • X[:, 1]은 점수 열이고 argsort는 점수가 작은 행의 원본 위치 [1,2,0]을 반환한다.
  • X[order]는 같은 순서를 모든 열에 적용하므로 [2,90] 같은 ID-점수 한 쌍이 깨지지 않는다.
PYTHON
X = np.array([[2, 90], [1, 70], [3, 80]]) # 원본 ID-점수 세 쌍
column_sorted = np.sort(X, axis=0)         # → [[1,70],[2,80],[3,90]]
# 위 결과에는 원본에 없던 [2,80]과 [3,90]이 생긴다.

order = np.argsort(X[:, 1])                # 점수순 원본 위치 → [1 2 0]
row_sorted = X[order]                      # → [[1,70],[3,80],[2,90]]
# 원본 행을 통째로 옮겨 ID-점수 쌍이 유지된다.

전체 정렬 없는 상·하위값 선택

23 · NUMPY

전체 정렬 없는 상·하위값 선택

분할

  • np.partition(x, 3)[:3]은 가장 작은 값 세 개를 왼쪽에 모으지만, 예제 출력 [2,1,3]처럼 그 세 값 자체를 정렬하지는 않는다.
  • np.argpartition(x, 3)은 값이 아니라 원본 위치를 반환하며, x[order]로 읽으면 partitioned와 같은 분할 결과가 된다.

사용 조건

  • 하위 세 값의 집합만 필요하면 partitioned[:3]을 사용하고, 순위도 필요하면 np.sort(partitioned[:3])로 [1,2,3]을 만든다.
  • ID·이름 같은 다른 배열도 같은 위치로 골라야 하면 값 대신 원본 위치를 주는 argpartition을 사용한다.
PYTHON
x = np.array([7, 2, 3, 1, 6, 5, 4])  # 원본 값과 위치
partitioned = np.partition(x, 3)       # 값 분할 → [2 1 3 | 4 6 5 7]
order = np.argpartition(x, 3)          # 위치 분할 → [1 3 2 | 6 4 5 0]

print(partitioned[:3], partitioned[3:])  # 출력: [2 1 3] [4 6 5 7]
print(order[:3], order[3:])              # 출력: [1 3 2] [6 4 5 0] — 원본 인덱스
print(x[order])                           # 출력: [2 1 3 4 6 5 7]

assert set(partitioned[:3]) == {1, 2, 3}
assert np.array_equal(x[order], partitioned)

부분 정렬 기반 최근접 이웃

25 · NUMPY

부분 정렬 기반 최근접 이웃

세 점의 실제 거리 배열

  • 점 A=(0,0), B=(3,0), C=(0,4)의 거리는 3-4-5 삼각형이므로 손으로도 A-B=3, A-C=4, B-C=5를 확인할 수 있다.
  • points[:,None,:] - points[None,:,:]는 모든 점 쌍의 좌표 차이를 만들고 마지막 축의 제곱합과 제곱근이 거리 배열을 만든다.

그림 검산

  • 거리 배열의 각 행은 출발점 하나의 거리 목록이며, 대각선 0은 자기 자신까지의 거리이다.
  • 대각선을 무한대로 바꾼 뒤 가장 작은 원본 인덱스를 고르면 자기 자신을 제외한 최근접 이웃을 얻는다.
PYTHON
points = np.array([[0, 0], [3, 0], [0, 4]]) # A, B, C 좌표
difference = points[:, None, :] - points[None, :, :] # 모든 점 쌍의 차이
distance = np.sqrt(np.sum(difference ** 2, axis=-1)) # 3×3 거리 배열
# distance 출력: [[0., 3., 4.],
#                 [3., 0., 5.],
#                 [4., 5., 0.]]

search = distance.copy()
np.fill_diagonal(search, np.inf)  # 자기 자신은 후보에서 제외한다.
nearest = np.argpartition(search, 0, axis=1)[:, 0]
print(nearest)                    # 출력: [1 0 0] = A→B, B→A, C→A

이종 자료형의 행 단위 저장

구조화 배열

  • 구조화 배열은 각 행에 이름이 붙은 여러 필드와 필드별 dtype을 저장하는 NumPy 배열이다.
  • dtype=[('name','U10'), ('age','i4'), ('weight','f8')]에서 바깥 대괄호는 필드 목록이고 쉼표는 세 필드 정의를 구분한다.

튜플과 행 관계

  • 각 안쪽 튜플 ('Alice', 25, 55.0)은 한 사람의 세 필드 값이며 dtype 목록의 필드 순서와 일대일로 대응한다.
  • people['age'] < 30으로 행을 고른 뒤 name을 읽어도 같은 행의 Alice가 남으므로 이름·나이·몸무게의 관계가 유지된다.
PYTHON
people = np.array([
    ('Alice', 25, 55.0),
    ('Bob', 45, 85.5)
], dtype=[
    ('name', 'U10'),   # 필드 이름 name, 최대 10글자 유니코드 문자열
    ('age', 'i4'),     # 필드 이름 age, 4바이트 정수
    ('weight', 'f8')   # 필드 이름 weight, 8바이트 실수
])

print(people.dtype.names)     # 출력: ('name', 'age', 'weight')
print(people['age'])          # 출력: [25 45]
young = people[people['age'] < 30]
print(young['name'])          # 출력: ['Alice']

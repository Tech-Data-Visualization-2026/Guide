視 데이터시각화View vs Copy

19 · MEMORY

두 배열이 같은 데이터 버퍼를 보는지가 핵심입니다.

View · 공유

새 배열 객체가 원본 데이터 버퍼를 공유합니다.

원본 ─ slice → View
View 수정 ─────→ 원본 변경

Copy · 독립

새 데이터 버퍼에 값을 복제합니다.

원본 ─ copy → Copy
Copy 수정 ─────→ 원본 유지
기본 슬라이싱은 View, .copy()는 Copy를 만듭니다.
視 데이터시각화Edit Scope

20 · DECIDE

부분 배열의 수정이 원본에 전달될지를 먼저 결정합니다.

원본과 공유

같은 데이터를 함께 갱신하고 불필요한 복사를 피해야 한다면 View

/

원본 보존

독립적으로 수정하고 원본을 지켜야 한다면 Copy

np.shares_memory(original, part)로 실제 공유 관계를 확인합니다.

항상 복사하거나 항상 공유하지 않는 이유를 설명할 수 있어야 합니다.
視 데이터시각화Memory Test
VIEW_COPY_TEST.PY
import numpy as np

original = np.array([10, 20, 30, 40])
view = original[1:3]
copied = original[1:3].copy()

view[0] = 999
copied[0] = 999

assert original.tolist() == [10, 999, 30, 40]
assert np.shares_memory(original, view)
assert not np.shares_memory(original, copied)

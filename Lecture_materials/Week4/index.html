03 · PANDAS

Series는 값에 행 이름을 붙인다

코드와 실행 이유

  • import pandas as pd는 pandas를 관례적인 짧은 이름 pd로 불러온다.
  • pd.Series는 1차원 값에 index라는 행 이름과 name이라는 값의 의미를 붙인다.
  • 주문 번호를 인덱스로 넣었기 때문에 sales.loc[102]처럼 위치가 아니라 주문 이름으로 값을 찾을 수 있다.

실행 결과

PYTHON · 실행 코드
import pandas as pd

sales = pd.Series(
    [12000, 18000, 15000],
    index=[101, 102, 104],
    name="sales",
)
print(sales)
TEXT · 실행 결과
101    12000
102    18000
104    15000
Name: sales, dtype: int64

DataFrame은 이름 붙은 열을 함께 관리한다

04 · PANDAS

DataFrame은 이름 붙은 열을 함께 관리한다

코드와 함수별 의미

  • pd.DataFrame({...})는 같은 길이의 열들을 2차원 표로 묶고 딕셔너리 키를 열 이름으로 사용한다.
  • np.nan은 실수 열의 결측값이고 pd.array(..., dtype="Int64")는 정수와 <NA>를 함께 보존한다.
  • pd.Index(..., name="order_id")는 행 이름이 주문 식별자라는 뜻을 기록한다.

실행 결과

PYTHON · 실행 코드
import numpy as np

orders = pd.DataFrame({
    "customer_id": [1, 2, 1, 4],
    "region": ["Seoul", "Busan", "Seoul", "Jeju"],
    "sales": [12000.0, 18000.0, np.nan, 15000.0],
    "quantity": pd.array([1, 2, None, 1], dtype="Int64"),
}, index=pd.Index([101, 102, 103, 104], name="order_id"))
print(orders)

09 · PANDAS

loc와 iloc를 섞으면 다른 행을 고를 수 있다

반례로 구분하기

  • loc[101, ...]의 101은 이름이 101인 첫 주문을 뜻한다.

Series 연산은 같은 인덱스를 먼저 맞춘다

fill_value는 없는 값을 어떻게 계산할지 정한다

결측을 0으로 간주한 덧셈

  • .add는 +와 같은 덧셈 메서드이지만 fill_value 규칙을 함께 지정할 수 있다.

  • 실제로 모르는 값을 무조건 0으로 바꿔도 된다는 뜻은 아니므로 문제의 의미가 허용할 때만 쓴다.

unstack과 stack은 값이 아니라 표 모양을 바꾼다

긴 표와 넓은 표 사이 이동

  • .unstack("year")는 행 인덱스의 연도를 열로 올려 지역별 가로 비교가 가능한 넓은 표를 만든다.
  • .stack()은 열의 연도를 다시 행 인덱스로 내려 원래의 긴 구조로 되돌린다.
  • 두 연산은 관측값을 새로 계산하지 않고 같은 값을 다른 축에 배치한다.

실행 결과

PYTHON · 실행 코드
wide = indexed["sales"].unstack("year")
long_again = wide.stack()

print(wide)
print(long_again)

22 · PANDAS

concat은 같은 구조의 표 조각을 이어 붙인다

월별 주문을 행 방향으로 결합

  • pd.concat([jan, feb])는 열 구조가 같은 1월·2월 표를 기본 행 방향으로 이어 붙인다.
  • ignore_index=True는 각 조각의 기존 행 번호를 버리고 0부터 새 번호를 붙인다.
  • 원본 주문 식별자인 order_id 열은 그대로 보존된다.

실행 결과

PYTHON · 실행 코드
jan = pd.DataFrame({"order_id": [101, 102], "sales": [12, 18]})
feb = pd.DataFrame({"order_id": [103], "sales": [15]})

all_orders = pd.concat([jan, feb], ignore_index=True)
print(all_orders)

이름을 맞추고,

Series와 DataFrame은 값에 Index와 열 이름을 붙여 행과 열의 의미를 보존한다.
대괄호는 열, loc은 이름, iloc은 정수 위치, 불리언 마스크는 조건으로 행과 열을 선택한다.
pandas 연산은 같은 인덱스와 열 이름을 먼저 맞추며 fill_value는 한쪽에 없는 값의 계산 규칙을 정한다.
dropna는 필요한 값이 없는 행을 제거하고 fillna는 명시한 가정으로 빈 값을 채운다.
MultiIndex와 stack·unstack은 같은 값을 다른 표 모양으로 재배치한다.
concat은 같은 열 구조의 표 조각을 행 방향으로 이어 붙이며 원본 order_id는 그대로 남긴다.

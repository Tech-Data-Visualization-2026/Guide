데이터 요약과 시계열 처리

Outline

거래 네 건에서 매장 담당자에게 전달할 범주·월별 매출 요약표를 만든다.

입력과 전달물

  • 전: 1월 drink 10·20, 2월 drink 30·food 40.
  • 후: 월별 30·70, 범주별 drink 60·food 40.

학습 순서

  • 문자열 정리 → 그룹 요약 → 행·열 교차표 → 시간값 변환과 구간 요약.
  • 같은 입력의 처리 전후를 비교한 뒤 선택·계산·검산까지 연결한다.

import pandas as pd
import numpy as np
sales = pd.DataFrame({
 "category": [" Drink ", "drink",
              "DRINK", "Food"],
 "channel": ["web", "web", "store", "store"],
 "sales": [10, 20, 30, 40],
}, index=[1, 2, 3, 4])
print(sales)
후 · 실제 실행 결과

1   Drink      web     10
2    drink     web     20

거래 한 건이 한 행

  • 이름 없는 행 인덱스 1–4가 거래 ID다. category는 범주, channel은 판매 경로, sales는 매출(천 원)이다.
  • 공백·대소문자가 다른 세 표기는 모두 음료 범주다. 정리한 뒤 합친다.

표 생성과 전달 목표

  • pd는 pandas, np는 NumPy의 별칭이다. {열 이름: 값 목록}으로 세 열을 만들고 index로 행 이름을 붙인다.
  • 총매출 100을 범주·경로별로 요약한다. 날짜 열은 시간 처리를 시작할 때 추가한다.

열 전체에 같은 규칙을 적용하는 벡터화 문자열 연산

    category
1   " Drink "
2   "drink"
3   "DRINK"
4   "Food"
연산 · 분석 노트북 셀
sales["category_clean"] = (
 sales["category"].astype("string")
 .str.strip().str.lower()
)
print(sales["category_clean"])
후 · 실제 실행 결과
1    drink
2    drink
3    drink

연산 순서와 각 줄의 역할

  • astype("string")은 결측을 보존하는 문자열 자료형으로 바꾼다. str은 열 전체에 문자열 연산을 적용하는 접근자다.
  • strip()은 양끝 공백을, lower()는 영문 대소문자 차이를 없앤다. " Drink " → "Drink" → "drink"다.

변한 값과 유지된 대응

  • 음료 세 행이 같은 키 drink를 갖는다. 매출 10·20·30과 거래 ID 1·2·3은 유지된다.
  • 원본 category 열을 남기고 category_clean 열을 추가한다. 반복문 없이 모든 행에 같은 규칙을 적용한다.

그룹별 합계·건수·평균

05 · PANDAS

그룹별 합계·건수·평균

전 · sales의 관련 두 열
    category_clean  sales
1   drink              10
2   drink              20
3   drink              30
4   food               40
연산 · 분석 노트북 셀
summary = sales.groupby("category_clean").agg(
 n=("sales", "size"),
 total=("sales", "sum"),
 avg=("sales", "mean")
)
print(summary)
후 · 실제 실행 결과
n  total   avg
category_clean                
drink           3     60  20.0
food            1     40  40.0

집계의 입력과 결과

  • drink 그룹은 ID 1·2·3의 세 행이다. 건수 3, 합계 10+20+30=60, 평균 60/3=20이다. food는 한 행이다.
  • agg(결과열=(입력열, 함수))다. n·total·avg는 새 열 이름이다. 키가 결과 인덱스가 되고 4행이 2행으로 줄어든다.

결측과 분모

  • size는 전체 행 수, count는 유효값 수다. [10, 결측, 30]이면 size=3, count=2, mean=20이다.
  • 이 입력의 매출·범주에는 결측이 없다. 그룹 키의 결측은 기본 제외되므로 실제 자료에서는 먼저 검사한다.

집계·변환·필터의 출력 행 수

06 · PANDAS

집계·변환·필터의 출력 행 수

전 · sales의 관련 열과 그룹
    category_clean  sales
1   drink              10
2   drink              20
3   drink              30
4   food               40

drink 그룹: ID 1·2·3 → 합 60
food 그룹:  ID 4 → 합 40
연산 · 분석 노트북 셀
group_total = sales.groupby(
 "category_clean")["sales"].transform("sum")
groups = sales.groupby("category_clean")
kept = groups.filter(lambda g: len(g) >= 3)
print(group_total)
print("남은 ID:", kept.index.tolist())
후 · group_total / 남은 ID
1    60
2    60
3    60
4    40
Name: sales, dtype: int64
남은 ID: [1, 2, 3]

합계를 원래 행에 대응시키는 transform

  • drink의 합계 60을 ID 1·2·3 각각에, food의 합계 40을 ID 4에 붙인다. 결과는 ID를 유지한 4행이다.
  • group_total은 그룹당 한 행의 표가 아니다. 예를 들어 ID 1의 그룹 내 비율은 10/60, ID 2는 20/60이다.

그룹 전체를 선택하는 filter

  • lambda g는 이름 없는 함수다. g에 drink의 원본 세 행이 들어오면 len(g)=3 → 참, food의 한 행이면 1 → 거짓이다.
  • 참인 그룹의 원본 행만 남긴다. 집계는 2행, transform은 4행, 이 filter는 ID 1·2·3의 3행이다.

두 범주를 행과 열로 배치하는 피벗 테이블

전 · sales의 교차 요약 입력
category_cleanchannelsales
1drinkweb10
2drinkweb20
3drinkstore30
4foodstore40
연산 · 분석 노트북 셀
matrix = sales.pivot_table(
 values="sales",
 index="category_clean",
 columns="channel",
 aggfunc="sum",
 fill_value=0,
)
print(matrix)
후 · 실제 실행 결과
channel         store  web
category_clean            
drink              30   30
food               40    0

행·열·셀의 대응

  • category_clean은 범주, channel은 판매 경로, sales는 매출이다. index는 결과 행, columns는 결과 열, values는 요약할 값을 지정한다.
  • drink×web에는 ID 1·2가 들어가므로 10+20=30이다. drink×store는 30, food×store는 40이다.

집계 방식과 빈 조합

  • 기본 집계는 평균이다. drink×web의 기본값 15와 합계 30은 다르므로 aggfunc="sum"을 명시한다.
  • food×web 거래는 없다. 전체 거래가 수록됐다는 가정으로 fill_value=0을 사용한다. 기록 누락이면 0으로 단정할 수 없다.

문자열 분해와 결측을 포함한 조건

전 · 별도 상품 태그 세 값
0  "Latte|HOT"
1  "hotdog|cold"
2  결측
연산 · 분석 노트북 셀
tags = pd.Series(
 ["Latte|HOT", "hotdog|cold", None], dtype="string")
parsed = tags.str.split("|", expand=True)
parsed.columns = ["item", "tag"]
print(parsed.to_string(index=False))
print(tags.str.contains("hot", case=False, na=False).tolist())
print((parsed["tag"].str.lower() == "hot").fillna(False).tolist())
후 · 실제 실행 결과
item  tag
 Latte  HOT
hotdog cold
  <NA> <NA>
[True, True, False]
[True, False, False]

분해 결과의 두 열

  • split("|", expand=True)는 구분자 양쪽을 별도 열로 만든다. 기본 False면 한 셀에 리스트를 넣는다.
  • 이 입력은 구분자가 하나다. columns로 두 열에 item·tag 이름을 붙이며 결측은 두 열 모두 <NA>로 남는다.

부분 일치와 정확한 태그

  • 출력 첫 목록은 contains의 부분 일치다. case=False는 대소문자 무시, na=False는 결측을 거짓으로 정한다.
  • hotdog도 부분 일치는 참이다. 두 번째 목록은 태그만 소문자로 바꿔 hot과 비교하고 결측을 거짓으로 채운 결과다.

시점·기간·간격과 시간 격자

09 · PANDAS

시점·기간·간격과 시간 격자

전 · 시점·기간·간격의 입력
시점: 2026-02-01 09:30
기간: 2026-02 한 달
간격: 2일

격자: 03-01부터 하루 간격 3개
연산 · 분석 노트북 셀
stamp = pd.Timestamp("2026-02-01 09:30")
period = pd.Period("2026-02", freq="M")
delta = pd.Timedelta(days=2)
days = pd.date_range("2026-03-01", periods=3, freq="D")
print(stamp + delta)
print(period)
print(days.strftime("%m-%d").tolist())
후 · 실제 실행 결과
2026-02-03 09:30:00
2026-02
['03-01', '03-02', '03-03']

시간값의 의미

  • Timestamp는 한 시점, Period는 한 달 같은 기간, Timedelta는 시간 간격이다. 시점에 이틀을 더해도 시각 09:30은 유지된다.
  • freq="M"은 여기서 월 기간을 뜻한다. 같은 문자열처럼 보여도 날짜 문자열과 계산 가능한 시간 객체는 다르다.

예상 시점의 목록

  • date_range는 시작일·개수(periods)·간격(freq)으로 시점 목록을 만든다. D는 하루 간격이다.
  • strftime은 날짜의 표시 형식만 바꾼다. %m은 월, %d는 일이다. 빈 날짜가 기록 누락인지 거래 미발생인지는 별도 판단한다.

10 · PANDAS

날짜 변환과 실패·결측 검사

전 · 별도 날짜 진단 입력
0  "2026-02-28"
1  "2026-02-30"
2  원래 결측
연산 · 분석 노트북 셀
sales["occurred_at"] = [
 "2026-01-03", "2026-01-10",
 "2026-02-01", "2026-02-14",
]
sales["occurred_at"] = pd.to_datetime(sales["occurred_at"])
assert sales["occurred_at"].notna().all()
probe = pd.Series(["2026-02-28", "2026-02-30", None])
checked = pd.to_datetime(probe, errors="coerce")
print(checked)
print("결측:", checked.isna().sum())
후 · 실제 실행 결과
0   2026-02-28
1          NaT
2          NaT
dtype: datetime64[ns]
결측: 2

기본 변환과 조사용 변환

  • 시간 처리를 시작하며 occurred_at 열을 추가한다. 목록의 네 날짜는 ID 1–4 순서다. to_datetime으로 시점으로 바꾸고 notna().all()로 결측 없음을 검사한다.
  • 별도 probe에서는 존재하지 않는 2월 30일과 원래 결측이 모두 NaT가 된다. NaT는 시간 결측이다.

실패와 결측의 구분

  • 기본 errors="raise"는 잘못된 날짜에서 중단한다. coerce는 변환 실패를 NaT로 남겨 원자료를 조사하게 한다.
  • isna().sum()은 결측 수 2를 센다. raise도 원래 결측은 허용할 수 있으므로 변환 성공과 필수값 검사는 별개다.

후 · 실제 실행 결과

시점을 월 구간으로 묶기

resample의 구간 집계와 asfreq의 격자 선택

13 · PANDAS

resample의 구간 집계와 asfreq의 격자 선택

전 · daily · 이름 없는 Series
2026-03-01    10
2026-03-02    20
2026-03-03    30
연산 · 분석 노트북 셀
daily = pd.Series([10, 20, 30],
 index=pd.date_range("2026-03-01", periods=3))
print("구간 합:", daily.resample("2D").sum().tolist())
print("격자 값:", daily.asfreq("2D").tolist())
후 · 실제 실행 결과
구간 합: [30, 30]
격자 값: [10, 30]

같은 입력의 두 결과

  • 2D는 이틀 간격이다. resample은 1·2일을 묶어 10+20=30, 3일 구간은 30을 낸다. 결과 날짜는 1·3일이다.
  • asfreq는 1·3일 격자에 있는 기존 값 10·30을 고른다. 2일의 20을 1일 값에 합치지 않는다.

선택 기준

  • 시간 구간의 통계가 필요하면 resample, 다른 시간 격자에 맞춘 기존 관측값이 필요하면 asfreq를 쓴다.
  • 이 장부터 빈 칸 채우기까지는 별도 일별 관측 예제다. 거래 네 건을 월별로 요약하는 앞 단계와 구분한다.

# pandas 선택과 결측값 처리 결과 확인

## 목표

같은 표에서 열 선택, 이름·위치에 따른 행 선택, 조건 필터, 결측값 제거와 채우기를 실행하고 결과를 비교한다. 모든 처리를 하나의 Python 파일에서 순서대로 실행한다.

## 제공 파일과 환경

- `README.md`: 실습 안내문.
- `students.csv`: 학생 5명의 가상 데이터. `student_id`는 행의 이름, `name`은 이름, `score`는 점수, `hours`는 학습 시간이다. 점수의 빈 칸은 관측하지 못한 값이며 0점과 다르다.
- 수업에서 사용한 Python과 pandas를 사용한다. pandas가 없다면 같은 Python 환경에서 `python -m pip install pandas`를 한 번 실행한다. 이 명령은 해당 환경에 pandas를 설치한다.

## 처리 순서

CSV를 `pd.read_csv("students.csv", index_col="student_id")`로 읽는다. `index_col`은 `student_id` 열을 행 이름으로 사용한다는 뜻이다. 원본 표의 행 순서를 유지한다. 아래 결과마다 번호와 제목을 붙여 출력한다.

| 단계 | 수행할 처리 | 확인할 결과 |
|---|---|---|
| 1 | 원본 표 출력 | 5행, 점수 결측 2개 |
| 2 | 대괄호로 `name`, `score` 두 열 선택 | 원본 순서의 5행과 두 열 |
| 3 | `loc`로 이름이 `S01`인 행 선택 | 민수, 점수 결측, 3시간 |
| 4 | `iloc`로 위치가 0인 행 선택 | `S03`: 지우, 80점, 2시간 |
| 5 | 원본에서 점수가 80 이상인 행 필터 | `S03`, `S05` 순서; 점수 80, 95 |
| 6 | 원본에서 `score`가 결측인 행을 `dropna`로 제거 | `S03`, `S05`, `S02` 순서; 3행 |
| 7 | 원본의 점수 결측값만 `fillna`로 0으로 채운 새 표 만들기 | 5행 유지; 점수 80, 0, 95, 60, 0 |

6번과 7번은 각각 원본에서 시작한다. 6번 결과를 7번의 입력으로 사용하지 않는다. 7번에서는 원본을 복사한 뒤 복사본의 점수 열에만 채우기를 적용한다. 마지막에 원본의 점수 결측 개수가 여전히 2개인지 출력해 확인한다.

0으로 채우는 것은 처리 차이를 관찰하기 위한 가정이다. 실제로 점수가 관측됐다는 뜻은 아니다. 그래프 작성은 요구하지 않는다.

## 작은 기대 결과

```text
조건 필터 행: S03, S05
결측 제거 행: S03, S05, S02
결측 채우기 점수: 80, 0, 95, 60, 0
원본 점수 결측 개수: 2
```

각 단계의 표 또는 행도 함께 출력한다. 표의 공백, 결측 표시(`NaN` 등), 숫자의 소수점 표시는 달라도 된다. 선택된 행·열, 값, 순서를 비교한다.

## 작성과 실행

AI와 함께 `main.py`를 작성한다. 주석과 빈 줄을 포함해 100줄 이내의 Python 파일 하나로 완성한다. 제공된 데이터를 코드 안에 옮겨 적거나 기대 출력만 직접 출력하지 말고, 파일을 읽어 결과를 계산한다.

학생 저장소의 `Week04/`에 제공 데이터를 복사하고 같은 폴더에 `main.py`를 작성한다. 터미널에서 `Week04/`로 이동한 뒤 아래 명령을 실행한다.

```bash
python main.py
```

이 명령은 입력 파일을 읽고 결과를 터미널에 출력한다. 입력 파일은 수정하지 않는다. 편집기 실행 버튼을 쓰는 경우에도 작업 폴더를 `Week04/`로 맞춘다. 환경에서 Python 명령이 `python3`이면 같은 명령 이름을 사용한다.

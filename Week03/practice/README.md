# 3주차 심화 실습 — 구간 경계와 중복 누적이 바꾸는 히스토그램

## 실습 목표

**실습 목표: 관측값을 구간 번호로 바꾸고 중복 인덱스를 빠짐없이 누적하여, 구간 경계 선택에 따른 분포 해석의 변화를 비교하는 Python 프로그램과 히스토그램을 구현한다.**

이 실습은 3주차 강의의 `np.searchsorted`, 팬시 인덱싱, `np.add.at`, 집계, 조건 마스크와 히스토그램을 하나의 흐름으로 연결한다. 새로운 집계 함수를 찾는 것이 아니라, 입력 관측값이 어떤 구간에 들어갔는지 추적하고 빈도 합·대표 관측값·그림의 막대 높이를 서로 대조하는 것이 핵심이다.

AI로 코드 초안과 설명을 만들 수 있다. 다만 AI 최초안, 직접 찾은 실패 또는 개선 기회, 수정한 최종안과 선택 이유를 제출물에 남겨야 한다. 최초안에 오류가 없다면 아래 기준선과 개선안을 비교한다.

## 쉬운 입력·출력 예제

입력 관측값은 `x = [0.2, 0.7, 0.8, 1.4, 1.8]`, 구간 경계는 `bins = [0.5, 1.0, 1.5, 2.0]`이다.

1. `np.searchsorted(bins, x)`로 구간 번호 `[0, 1, 1, 2, 3]`을 만든다.
2. 길이 5인 0 배열에 `np.add.at(counts, index, 1)`을 적용한다.
3. 기대 빈도 `[1, 2, 1, 1, 0]`과 실제 빈도가 같은지 확인하고, 빈도 합 5가 입력 수 5와 같은지 `assert`한다.

같은 인덱스 `[0, 1, 1, 2, 3]`에 `bad[index] += 1`을 적용하면 `[1, 1, 1, 1, 0]`이 된다. 1번 구간을 두 번 방문했지만 같은 값 1을 되쓰기 때문에 사건 하나가 사라진다. 이 결과의 합 4와 올바른 결과의 합 5를 나란히 출력한다.

## 필수 작업

### 1. 작은 입력으로 누적 과정을 검산한다

- 위 쉬운 예제를 그대로 실행해 `index`, 잘못된 빈도, 올바른 빈도와 각각의 합을 출력한다.
- `index[1] == index[2] == 1`과 올바른 빈도 배열을 `assert`한다.
- 관측값 `0.2`, `0.7`, `1.4`, `1.8`의 구간 번호를 손으로 계산한 표와 실제 `index`를 대조한다.

실패 징후는 올바른 빈도 합이 입력 수와 다르거나 대표 관측값의 예상 구간과 실제 구간이 다른 경우다.

### 2. 구간 경계가 해석을 바꾸는지 비교한다

최솟값과 최댓값이 같은 범위를 덮되 폭이나 위치가 다른 경계 배열 두 개를 직접 설계한다. 각 경계에 대해 경계 배열, 생성된 구간 번호, 구간별 빈도, 빈도 합을 기록한다. 평균·중앙값은 같아도 분포 그림에서 달라진 막대와 그 이유를 설명한다.

경계와 정확히 같은 관측값을 최소 하나 넣어 `np.searchsorted`의 실제 구간 번호를 출력한다. 경계 포함 방향을 추측하지 말고 출력으로 판정한다.

### 3. 중복률이 높은 반례를 만든다

관측값 12개 이상이 특정 구간 두 곳에 몰리도록 입력을 직접 만든다. 이 입력에 일반 팬시 인덱싱 대입과 `np.add.at`을 모두 적용한다.

- `입력 수 - 잘못된 빈도 합`으로 사라진 사건 수를 계산한다.
- 각 구간의 기대 빈도를 손으로 센 작은 표와 `np.add.at` 결과를 비교한다.
- 중복이 없는 별도 입력에서는 두 방식의 결과가 같아지는지도 확인한다.

목적은 “항상 `np.add.at`이 낫다”를 주장하는 것이 아니라, 중복 인덱스 누적이 필요한 조건을 반례로 구분하는 것이다.

### 4. 빈도와 가중합을 구분한다

각 관측에 양의 가중치 배열을 하나 대응시킨다. 같은 구간 번호에 `np.add.at(counts, index, 1)`로 빈도를, `np.add.at(weight_sum, index, weights)`로 가중합을 만든다.

`counts.sum() == len(x)`와 `np.isclose(weight_sum.sum(), weights.sum())`을 검증한다. 한 원소가 “관측 한 건”인지 “가중치 한 단위”인지 구분하고, 빈도와 가중합 막대그래프가 답하는 질문이 왜 다른지 설명한다.

### 5. 그림을 원자료까지 되짚어 검증한다

두 경계 설계의 빈도를 같은 축 범위의 나란한 막대그래프로 저장한다. 막대 수가 `len(bins) + 1`인지, 막대 높이의 합이 입력 관측 수인지, 대표 구간 하나의 막대 높이가 그 구간에 들어간 원자료 수인지 검사한다.

`histogram_comparison.png`가 존재하고 크기가 0보다 큰지도 코드로 확인한다. 모양이 예쁘다는 사실은 정확성 근거가 아니다.

## 열린 개선 과제

두 경계 중 질문을 더 잘 설명하는 하나를 선택하거나 세 번째 경계를 제안한다. `특정 구간에 관측이 과도하게 몰리는가`, `비교할 기준값 전후가 드러나는가`, `빈 구간이 지나치게 많은가`, `경계를 조금 옮겨도 결론이 유지되는가` 중 최소 두 기준을 실제 출력과 그림에 적용한다.

정답 경계는 하나가 아니다. 선택한 경계가 답하는 질문, 잃는 세부정보, 다른 데이터에서는 부적절할 수 있는 조건을 함께 기록한다.

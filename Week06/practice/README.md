# 부스 방문 현황의 시각화 보고

체험 부스 담당자에게 방문자 수의 시간 변화와 기온별 방문 현황을 전달한다. 제공 CSV의 관측값을 보존하며 선 그래프와 산점도를 PNG 두 장으로 완성하는 하나의 실습이다.

서술형 응시를 위해 **17:00까지 교수자 앞으로 나와야 한다.** 17:00은 실습 마감 30분 후이며, 모든 학생의 서술형 풀이를 수업 종료에 맞춰 마치기 위한 응시 도착 기한이다.

## 제공 입력과 실행 환경

제공 파일은 `README.md`와 `visitors.csv`다. 한 행은 하루의 관측이며 수업용 가상 자료다. `day`는 일차, `temp`는 기온(°C), `a`와 `b`는 각 부스 방문자 수(명), `wait`는 A 부스 대기시간(분)이다. 행이 시간순으로 저장되어 있지 않다.

```csv
day,temp,a,b,wait
3,20,30,35,4
1,18,20,18,2
4,24,50,45,6
2,22,40,32,8
```

Python 3, pandas, Matplotlib을 사용한다. 예시 구현은 pandas 1.4.4와 Matplotlib 3.5.2에서 실행했다. 스타일은 내장 `classic`을 사용하며, 차트의 영문 라벨은 아래 대응표를 따른다. Python 파일과 CSV가 있는 폴더에서 실행한다.

| 명령 | 읽는 대상과 목적 | 바뀌는 파일·확인 결과 |
|---|---|---|
| `python --version` | Python 실행기 확인 | 파일 변경 없이 버전 출력 |
| `python -c "import pandas, matplotlib; print(pandas.__version__, matplotlib.__version__)"` | 설치된 라이브러리 확인 | 파일 변경 없이 두 버전 출력 |
| `python main.py` | 현재 폴더의 `visitors.csv`를 읽어 그림 생성 | `output/trend.png`, `output/relationship.png` 생성 또는 덮어쓰기 |

AI로 코드 초안을 작성해도 된다. 실제 출력과 기대값을 직접 대조한다. GUI 창을 띄우지 않고 파일만 저장해도 실습을 완료할 수 있다.

## 처리 순서와 기대 출력

1. CSV를 읽고 `day` 기준으로 **행 전체**를 정렬한다. 네 행을 유지하고 아래 날짜별 값의 대응을 확인한다. `day`만 정렬하면 방문자·기온·대기시간의 짝이 깨진다.
2. `classic` 스타일을 새 그림 생성 전에 적용한다. `output/trend.png`는 A와 B의 시간순 선 그래프다. 두 선의 점 개수는 각각 4개이며, A는 남색 실선·원, B는 회색 점선·사각형으로 표시한다. 계열 이름과 모양을 연결한 범례를 넣는다.
3. `output/relationship.png`는 가로 기온, 세로 A 방문자 수인 산점도다. 점 네 개의 크기는 같은 행의 `wait`에 40을 곱한 값으로 지정한다. 원형 마커, 같은 남색, 테두리 두께 0을 사용한다. 제목에 크기 규칙을 적어 대기시간의 의미를 읽을 수 있게 한다.
4. 두 그림 모두 8×5인치, 세로축 0~60, 150dpi로 PNG를 저장한다. `bbox_inches="tight"`는 사용하지 않아 각 이미지의 크기를 1200×750픽셀로 유지한다. 실제 파일을 열어 라벨·제목·범례가 잘리지 않았는지 확인한다.

| day | temp | a | b | wait | 산점도 크기 s (pt²) |
|---:|---:|---:|---:|---:|---:|
| 1 | 18 | 20 | 18 | 2 | 80 |
| 2 | 22 | 40 | 32 | 8 | 320 |
| 3 | 20 | 30 | 35 | 4 | 160 |
| 4 | 24 | 50 | 45 | 6 | 240 |

예를 들어 둘째 날은 추이 그림의 A 선에서 `(2, 40)`, 관계 그림에서 `(22, 40)`·`s=320`으로 나타난다. `s`는 포인트 제곱 단위의 크기 척도다. 같은 원형 마커에서 80→320은 크기 척도 4배, 가로 길이 2배다.

| 출력 파일 | 제목 | 가로축 | 세로축·추가 표시 |
|---|---|---|---|
| `output/trend.png` | `Booth visitors by day` | `Day` — 일차 | `Visitors (people)` — 방문자 수(명); 범례 `Booth A`, `Booth B` |
| `output/relationship.png` | `Booth A: marker size = 40 x wait (min), pt^2` | `Temperature (C)` — 기온(°C) | `Visitors (people)`; 제목은 크기 40×대기시간(분), 단위 pt²를 뜻함 |

그림에서 A는 2일차 40명에서 3일차 30명으로 감소하고, 3일차에는 B 35명이 A보다 많다. 관계 그림에서는 이 네 관측의 기온과 A 방문자가 함께 증가한다. 이 관측만으로 기온의 인과 효과를 확정하지 않는다.

네 행의 값과 크기 배열을 검산하고 두 파일의 저장을 완료하면 터미널에 다음을 출력한다.

```text
OK: 4 days; 2 figures; 1200x750 pixels each
```

이 문장만으로 정답을 판정하지 않는다. 두 PNG의 실제 크기·내용과 재실행 결과를 함께 확인한다.

## 제출 파일과 평가기준

제출물은 `main.py` 한 개와 생성한 `output/trend.png`, `output/relationship.png`다. Python 소스는 빈 줄과 주석을 포함해 100줄 이내다. 개인 이해도는 실습 종료 후 교수자가 현장에서 확인하고 Discord 비공개 서술형 문항 한 개로 별도 평가한다.

| 평가기준 | 제출물의 직접 증거 |
|---|---|
| 제출한 Python 소스가 .py 파일 한 개이고 100줄 이내인가? | 소스 파일 개수와 빈 줄·주석을 포함한 전체 줄 수 |
| 네 관측의 대응을 보존하여 두 차트를 구성했는가? | 재실행한 추이의 날짜별 A·B 값, 산점도 좌표와 s=[80,320,160,240], 원본 행과의 대응 |
| 두 PNG를 요구한 크기와 읽을 수 있는 설명으로 저장했는가? | 두 파일 각각 1200×750픽셀, 세로축 0~60, 제목·축 라벨·범례·크기 규칙의 일치와 비절단 |
